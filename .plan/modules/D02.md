## 一、本模块要解决什么问题 / 教学点
用 `docker compose` 一键把开发期两个数据库跑起来：**MySQL 8（业务库）** 与 **PostgreSQL + pgvector（知识库）**。
教学点：镜像 vs 容器、compose 三段式（services/volumes/networks）、端口映射、命名卷持久化、healthcheck、`.env` 注入与 `$$` 转义、为什么"数据库也用容器跑"。
后续 M1（MySQL 建模）与 M2（pgvector 知识库）都建立在它之上。

## 三、交付物与验收
- 根目录 `docker-compose.yml`：`mysql`(mysql:8.0) + `postgres`(pgvector/pgvector:pg16) 两个 service
- `.env`（本地，不入库）+ `.env.example`（提交模板，占位密码）
- `docker/postgres/init/01-enable-vector.sql`（`CREATE EXTENSION IF NOT EXISTS vector;`）
- 验收（在仓库根目录执行并截图/贴输出）：
  ```
  docker compose config
  docker compose up -d
  docker compose ps                 # 两个都要 healthy
  docker compose exec mysql mysql -ucitong -p<密码> -e "SELECT VERSION(); SHOW VARIABLES LIKE 'character_set_server';"
  docker compose exec postgres psql -U citong -d citong -c "CREATE EXTENSION IF NOT EXISTS vector; SELECT extname, default_version FROM pg_available_extensions WHERE extname='vector';"
  ```
- 验证后**保持容器运行**（不要 down），M1/M2 还要用。
