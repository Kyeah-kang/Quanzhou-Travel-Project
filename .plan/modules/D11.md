## 二、本模块要解决什么问题 / 教学点
M1 存的是"结构化主数据"（`heritage_sites` 表）；M2 起要往 PG 里灌**非结构化长文分块 + 向量**。在灌之前必须先定义**语料长什么样**——否则 D16 切分、D17 嵌入、D18 检索全无依据。D11 就是定这个"语料合同"。
教学点（老师精讲）：
① **frontmatter 不是装饰，是检索的燃料**：`site_key` 决定 metadata 过滤（"只查清净寺"），`tags`/`category` 决定筛选与行程编排，`source` 决定引用溯源——**今天定的字段，就是 D18「metadata 过滤」和 M3「输出引用来源」的输入**；
② **一份语料两个消费者**：同一份 `.md` 的 frontmatter 既要**灌 MySQL `heritage_sites`**（结构化主数据），又要**随正文进 PG documents 的 metadata**（检索过滤）——所以字段要对齐 `docs/architecture.md` §4.1/§4.2，不能各写各的；
③ **正文结构与切分策略耦合**：固定 `## 概述/历史沿革/遗产价值/看点与细节/实用信息/常见问答` 六节，是为了让 D16 能**按标题切块**、每块自带语义边界；FAQ 节尤其重要（问答对天然适合 RAG）；
④ **异说处理原则（本课重点）**：同一事实多个来源打架时（如洛阳桥长度 834m vs 731.29m），**不许挑一个装作没有异说**——两个都记、标 `待校对`、注明"以官方公布/实测为准"。这是"保真"与"编造"之间的真正分界线；
⑤ **先手写再框架**：frontmatter 解析用 PyYAML **手写**校验，不直接上 `python-frontmatter`/LangChain loader——延续项目原则 2；
⑥ **行程约束字段（本次增补，本课重点）**：为 M5 预留 `visit_duration_min`（参观时长）、`theme`（适合的行程主题）、`notice`（游览注意事项）——**只设计字段与英文名，不实现任何行程逻辑**。它们属"结构化、可硬过滤"数据：落 MySQL，同时镜像进 PG metadata，服务 D18 的"先硬过滤再向量召回"；
⑦ **溯源规则必须机器可校验（本次增补，本课重点）**：`fact_status: 已核对` ⇔ `pending_fields: []`；事实字段无来源时数值填 `null`、文本填 `待校对`，**且字段名必须列入 `pending_fields`**——这样 D15 的质检脚本与"数据完整率"才能直接算出来，而不是靠人读散文判断。字段分三类（事实 / 编辑归类 / 派生），见 §4.1。

### 4.1 `docs/corpus-spec.md` 要点

**① 字段三分类（决定"要不要来源"）**
- **事实字段**（须来源）：`name` / `alias` / `category` / `key_element` / `area` / `lat` / `lng` / `address` / `open_hours` / `visit_duration_min` / `notice`
  → 无可靠来源时：**数值填 `null`、文本填 `待校对`**，且**字段名必须列入 `pending_fields`**
- **编辑归类字段**（不要求来源，但必须取自受控词表）：`theme`、部分 `tags`
- **派生 / 元数据字段**：`site_key`、`source`、`fact_status`、`updated`

**② 字段 × 消费者 分工表**（同一份 frontmatter，两个消费者）

| 字段 | MySQL `heritage_sites` | PG `documents.metadata` | 用途 |
|---|---|---|---|
| `site_key` | ✅（唯一键） | ✅（作 `doc_key`） | 站点标识 / 硬过滤 |
| `name` / `alias` | ✅ | ✅ | 展示；别名检索（D19「别名类」评测） |
| `area` | ✅（索引） | ✅ | 区域筛选、就近分组（M5） |
| `category` / `key_element` | ✅（索引） | ✅ | 分类筛选、主题分组 |
| `lat` / `lng` | ✅ | ✅ | 地理就近（M5 约束） |
| `open_hours` | ✅ | ✅ | **硬约束**（M5） |
| `visit_duration_min` | ✅ | ✅ | **时间预算约束**（M5） |
| `theme` | ✅ | ✅ | 行程主题匹配（M5） |
| `notice` | ✅ | ✅ | 游览提示（M5 / 前端展示） |
| `tags` / `intro_short` | ✅ | — | 列表展示、轻量筛选 |
| `source` | ✅ **仅短引文** | ✅ **完整列表** | 引用溯源（M3 作答标注） |
| `fact_status` / `pending_fields` | ✅ | ✅ | 数据可信度标注 / 质检统计 |

> MySQL 只存短引文、完整来源列表留在语料与 PG metadata —— 不在 MySQL 重复存大字段，避免两处口径漂移。

**③ 受控词表**
- `category` ∈ { 港口码头, 桥梁, 航标塔, 城市遗址, 管理机构, **文教建筑**, 宗教建筑, 墓葬, 石刻, 窑址, 冶铁遗址 }
  （新增「文教建筑」：原表无法归类 **泉州府文庙**；**扩表须写明理由**）
- `key_element` ∈ { 机构保障, 多元社群, 城市结构, 生产基地, 交通网络, 整体格局 }（按申遗六大关键要素；**属事实字段**——未核到申遗文本原文者须列入 `pending_fields`）
- `theme` ∈ { 海丝溯源, 宗教多元, 古建桥梁, 非遗体验, 城市漫步, 亲子研学 }（**编辑归类**，本日初版，D12–D14 可复核调整）
- `fact_status` ∈ { 已核对, 待校对 }
- **词表覆盖性校验（本日必做）**：把 22 处逐一归入 `category` / `key_element` / `theme`；**不可归类者 → 扩表 + 写理由**，不许硬塞。

**④ 溯源规则（机器可校验）**
- `fact_status: 已核对` ⇔ `pending_fields: []`
- `pending_fields` 列出的字段，其值必须是 `null` 或 `待校对`；**若已填了值但尚未核到来源**（如本日样例的 `key_element`），同样必须列入 `pending_fields`，并在汇报中单独列出供老师核对
- `source` 非空，每项含 `title` / `url` / `accessed`

**⑤ 命名与正文结构**
- `site_key` = 文件名（去 `.md`），小写英文蛇形；一站点一文件；主题语料用 `topic_*` 前缀
- 正文六节固定：`## 概述` / `## 历史沿革` / `## 遗产价值` / `## 看点与细节` / `## 实用信息` / `## 常见问答`；每节 ≤ 500 字为宜（便于 D16 按标题切块）

**⑥ 异说记录格式**
`> ⚠️ 异说：A 来源作 X，B 来源作 Y，以官方公布为准（待校对）`

## 概述

九日山祈风石刻位于福建省泉州市南安市丰州镇九日山，是宋代泉州地方政府主持航海祈风祭祀活动留下的官方石刻记录。2021 年作为「泉州：宋元中国的世界海洋商贸中心」的遗产点之一列入《世界遗产名录》。

## 历史沿革

宋代泉州海外贸易兴盛，出海与回航依季风而行。每年冬季启航前、夏季回航前，泉州地方官员与市舶司官员会在九日山举行祈风祭典，祭毕将经过刻于崖壁，遂成祈风石刻。石刻铭文中出现「遵令典」「修故事也」「遵彝典也」等语；两知泉州的真德秀曾点明祈风乃「国有典祀」，表明至迟在 12 世纪中叶，九日山祈风已由民间行为上升为列入国家祭典的官方活动。

## 遗产价值

现存宋代航海祈风石刻共 10 方，是现存唯一的古代中国政府有关航海的国家祭典石刻文字记录。

## 看点与细节

- **分布**：东峰 2 方，西峰 8 方。
- **年代跨度**：最早的为南宋淳熙元年（1174 年），最晚的为南宋咸淳二年（1266 年）。
- **内容构成**：记载冬季启航祈风 6 方、夏季回航祈风 3 方，另有 1 方同时记载一年两季的祈风。
- **参与者**：碑文记载历次参与祈风的市舶司官员共 9 人，泉州地方军政要员共 58 人，其中 18 人为南宋皇族。

> ⚠️ 异说：九日山现存摩崖石刻总数与祈风石刻方数，各家表述不一——主流说法为全山现存石刻 78 方、其中宋代祈风石刻 10 方；亦有资料作 77 方、75 方，或「祈风石刻 13 方」之说。本文采用主流说法，其余待校对。
> ⚠️ 异说：部分来源提到这 10 方石刻记载了 1174 年至 1266 年间共 11 次官方祭祀活动，次数与方数的对应关系待校对。

- 开放时间：待校对（以景区公示为准）。

- **明善堂**：位于奉天坛北侧，始建于明隆庆元年（1567 年），为砖木结构的礼拜堂。

## 概述

洛阳桥原名万安桥，位于福建省泉州市洛阳江入海口（洛阳口），距泉州城约 5 公里，是中国现存最早的跨海梁式石桥，有「海内第一桥」之誉，为全国重点文物保护单位。

## 历史沿革

据多个来源，该桥始建于北宋皇祐五年（1053 年），至嘉祐四年（1059 年）建成。北宋泉州知州蔡襄主持修造，并题写《万安桥记》。

> ⚠️ 异说：建造主持者，部分资料指出工程最初由泉州开元寺僧人宗已和郡人王实、卢锡倡建，蔡襄于嘉祐三年（1058 年）第二次出知泉州时积极着手续建，至嘉祐四年十二月竣工；亦有资料认为蔡襄的「倡建者」身份系后世讹传。待校对。

## 遗产价值

洛阳桥的建造针对洛阳江潮狂水急、桥基屡被摧毁的难题，首创两项工程技术：

- **筏形基础**：用船载石沿桥的中轴线抛下大量石块，使江底形成一条连结江底的矮石堤，然后在堤上建造船形桥墩。这被认为是世界桥梁筏形基础的开端。
- **种蛎固基**：在桥基石上养殖牡蛎，利用牡蛎生长迅速、繁殖力强、胶凝性好的特性，将江底石块黏合成坚固的整体基础。这是世界上把生物学应用于桥梁工程（巩固桥基）的先例，洛阳桥也因此被称为首座将生物学应用于巩固桥基的古桥。

## 看点与细节

- 桥上及周边现存石亭、石塔、石将军像、碑刻等附属文物。
- 蔡襄撰书的《万安桥记》宋碑立于桥南蔡襄祠内，被誉为书法、记文、雕刻「三绝」。

> ⚠️ 异说：桥的规模各来源不一——有资料称桥长 834 米、宽 7 米，桥墩 46 座；泉州市政府网站及较近的实测数据（1993 年实测）则作全长约 731 米（731.29 米）、宽约 4.5 米、高约 7.3 米，有 44—47 孔、44—46 座船形桥墩。待校对。

### 4.6 `app/rag/corpus.py`（解析）+ `backend/app/ingest/corpus_check.py`（结构校验）
- `app/rag/corpus.py`：用 **PyYAML** 解析 `data/raw_md/*.md` 的 frontmatter（`---` 围栏）→ 统一文档模型，供 D16 切分、D17 索引复用；**不引入** `python-frontmatter` / LangChain loader
- `app/ingest/corpus_check.py`：CLI（在 `backend/` 下 `python -m app.ingest.corpus_check`），逐文件输出 PASS/FAIL，校验项：
  ① 必填字段齐全；② `site_key` == 文件名；③ `alias`/`tags`/`theme`/`pending_fields` 为列表；④ `source` 非空且每项含 `title`/`url`/`accessed`

  ⑨ 正文六个 `## ` 标题齐全且**顺序一致**
- 退出码：有 FAIL 返回 1；报告与注释用中文，注释只写关键"为什么"
