## 一、本模块要解决什么问题 / 教学点
把 FastAPI 后端的**骨架**立起来：app 工厂、配置与 `.env`（pydantic-settings）、CORS、`/api/health`、日志。
教学点：① app 工厂模式 vs 模块级裸 app；② 配置外置（一切可配置项进 `core/config.py`，绝无硬编码）；③ 前后端分离为何要 CORS；④ 标准库 `logging` 的级别/格式从配置来，不 `print`；⑤ Monorepo 里**一个根 `.env` 供 docker-compose 与 backend 共用**，pydantic-settings 如何定位它。
后续 D04 起（M1 数据层）在骨架上长 SQLAlchemy/路由，都在这个 `app/` 结构里。

## 三、交付物与验收

### 交付物（都在 backend/ 下）
- `backend/pyproject.toml`：包 `citong-backend`、`requires-python>=3.13`；依赖 `fastapi` `uvicorn[standard]` `pydantic-settings`；dev 依赖 `pytest` `httpx` `ruff`；setuptools 打包，包发现 `include=["app*"]`
- `backend/app/main.py`：`create_app()` 工厂 + `app = create_app()`；注册 CORS 中间件（origins 来自 settings）；`include_router(..., prefix="/api")` 挂 health 路由；`setup_logging(settings.log_level)`；启动时打一条 INFO（服务名/版本/env）
- `backend/app/core/__init__.py`、`backend/app/core/config.py`：pydantic-settings `Settings(BaseSettings)`，`env_file` 指向**仓库根 .env**（用 `Path(__file__)` 上溯定位，勿假设 CWD）
- `backend/app/routers/__init__.py`、`backend/app/routers/health.py`：`GET /api/health` → `{"status":"ok","service":<project_name>,"version":<version>}`
- 根 `.env` 与 `.env.example` 各追加（**DB 键值不动**）：`PROJECT_NAME` `APP_ENV` `DEBUG` `LOG_LEVEL` `CORS_ORIGINS`
- `backend/tests/test_health.py`：1 个冒烟测试（TestClient GET /api/health == 200 且 status=ok）

### config.py 要点（防翻车的 3 处）
1. 根定位：`Path(__file__).resolve().parents[3]` 即仓库根（`backend/app/core/config.py` 上溯 3 级）。`model_config = SettingsConfigDict(env_file=仓库根/".env", env_file_encoding="utf-8", extra="ignore")`
2. `cors_origins: list[str]` 在 `.env` 里用 **JSON 数组**写法：`CORS_ORIGINS=["http://localhost:5173"]`
3. 默认值兜底（缺键不报错）；字段命名小写下划线，环境变量名自动映射成大写下划线

### 验收（在 backend/ 激活 venv 后执行，贴真实输出，不许谎报）
```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
ruff check .
pytest -q                 # 1 passed
uvicorn app.main:app --reload   # 起在 8000
```
另开一个终端：
```
curl http://127.0.0.1:8000/api/health     # → {"status":"ok","service":"刺桐智游",...}
curl http://127.0.0.1:8000/docs           # Swagger 可开
```
- 确认 uvicorn 启动时打出的 INFO 日志含服务名，且改 `LOG_LEVEL=DEBUG`（临时）后能看到 debug 级日志、改回后消失（证明日志级别读自 `.env`）
- 确认 `.env` 新增键已加、`.env.example` 同键加了**安全默认值**（不写真实密码，CORS_ORIGINS 给 localhost:5173）
