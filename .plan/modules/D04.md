## 二、本模块要解决什么问题 / 教学点
把「后端连得上 MySQL」这件事做扎实：SQLAlchemy **engine（连接池）→ sessionmaker → Session** 三层，`DeclarativeBase` 定义 ORM 模型，落地第一张表 `users`，并打通 `config` 单一来源的 DSN。
教学点：① engine 是"连接池管家"、Session 是"一次工作单元"——二者区别与线程安全；② **同步 vs 异步取舍**（本模块决策题：选同步、PyMySQL，理由 = 学习曲线/易调试/repository 分层日后升 async）；③ SQLAlchemy 2.0 类型化 `Mapped`/`mapped_column` 写法；④ `server_default=func.now()` 把"当前时间"交给 DB 而非 Python；⑤ `pool_pre_ping`（容器重启后连接不过期）；⑥ 密码只在一个地方（.env 的 MYSQL_PASSWORD），DSN 由 config **拼出来**，杜绝 `DATABASE_URL` 里的密码与 .env 漂移——呼应 D02 改密码的教训。

## 四、交付物与验收

### config 追加（backend/app/core/config.py）
- 新字段：`mysql_host`(默认 127.0.0.1) `mysql_port`(默认 3307，int) `mysql_user`(citong) `mysql_password`(默认空串，靠 .env) `mysql_database`(citong)
- 新只读属性 `mysql_dsn`：`mysql+pymysql://<quote_plus(user)>:<quote_plus(pass)>@<host>:<port>/<db>?charset=utf8mb4`
- **禁止把 DSN 打日志/打印**（含密码）；测试只断言前缀，不断言全文

### 数据层
- `db/base.py`：`class Base(DeclarativeBase): pass`
- `db/engine.py`：`engine = create_engine(settings.mysql_dsn, pool_pre_ping=True, echo=settings.debug)`
- `db/session.py`：`SessionLocal = sessionmaker(bind=engine, autoflush=False)`；`get_db()` 生成器 yield Session、finally close（供日后路由 `Depends`）
- `models/user.py`（表名 `users`）：id PK；username String(50) not null unique；email String(255) unique；hashed_password String(255) not null；nickname String(50) null；avatar String(255) null；created_at/updated_at DateTime `server_default=func.now()`，updated_at 加 `onupdate=func.now()`
- `models/__init__.py`：`from app.models import user  # noqa`（触发元数据注册）

### 验收（在 backend/ 用 uv，两个 MySQL 容器须 healthy；贴真实输出）
```
uv sync --extra dev
uv run ruff check .
uv run pytest -q                    # test_db.py: DSN 前缀 / SELECT 1 连通 / 元数据含 users
uv run python -c "import app.models; from app.db.base import Base; from app.db.engine import engine; Base.metadata.create_all(bind=engine); print('users created')"
# 再用 MySQL 客户端确认表结构（键不改动值）：
docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_PASSWORD" mysql -ucitong citong -e "SHOW TABLES; DESCRIBE users;"'
```
- `create_all` 可重复执行（幂等）；确认 MySQL 里 `users` 表存在、utf8mb4、username/email 唯一索引在位
