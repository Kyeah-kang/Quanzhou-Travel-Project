## 四、交付物与验收

### 表设计（字段口径以 architecture §4.1 + 本处为准；FK 列加 index）
- `users`：沿用 D04（勿改）
- `heritage_sites`：id PK · site_key String(50) uq not null · name String(100) not null · alias JSON null（别名列表）· area String(50) not null(index，县市区) · category String(50) not null(index，功能分区) · unesco_group String(50) null · lat/lng Float null · address String(255) null · open_hours String(255) null · tags JSON null · intro_short String(1000) null · source String(255) null · created_at/updated_at(server_default func.now()+onupdate)
- `chat_sessions`：id PK · user_id FK→users.id not null(index) · title String(100) not null · mode String(20) not null default 'qa' · site_key String(50) null(index) · created_at/updated_at
- `chat_messages`：id PK · session_id FK→chat_sessions.id not null(index, ondelete=CASCADE) · role String(20) not null · content Text not null · sources JSON null（引用来源）· created_at（无 updated_at）
- `itineraries`：id PK · user_id FK→users.id not null(index) · params JSON not null · content JSON not null · created_at
- `favorites`：id PK · user_id FK→users.id not null(index) · site_key String(50) not null · created_at · **UniqueConstraint(user_id, site_key)**（防重复收藏）

### Alembic 接入（关键交接）
1. `alembic init alembic`（backend/ 下）
2. `env.py`：从 `app.core.config.settings.mysql_dsn` 取 URL（**不在 ini 写死**）、`import app.models` + `target_metadata = Base.metadata`；不打印 DSN
3. 清场交接：`python -c "...Base.metadata.drop_all(bind=engine); print('temp schema dropped')"`（删掉 D04 的临时 users；dev 空库）
4. `alembic revision --autogenerate -m "init all tables"` → `alembic upgrade head`
5. 自检：`alembic current` / `alembic history`；MySQL `SHOW TABLES` 应有 7 张（6 业务表 + alembic_version）

### 验收（在 backend/.venv 激活后执行，MySQL 须 healthy；贴真实输出）
```
python -m pip install -e ".[dev]"     # 装 alembic
python -m ruff check .
python -m pytest -q                    # D04 测试仍应全绿（模型改动不破坏）
python -c "import app.models; from app.db.base import Base; from app.db.engine import engine; Base.metadata.drop_all(bind=engine); print('dropped')"
alembic revision --autogenerate -m "init all tables"
alembic upgrade head
alembic current
# 再用 MySQL 客户端确认表与结构（键不改动值）：
docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_PASSWORD" mysql -ucitong citong -e "SHOW TABLES;"'
```
