## 做得好的点（可当教材）
- **factory + 单例**：`create_app()` 可测、可换 settings；`app = create_app()` 供 uvicorn 导入
- **`.env` 根定位不依赖 CWD**：`Path(__file__).resolve().parents[3]` 上溯仓库根（backend/app/core/config.py → 仓库根），CWD 在哪都找得到
- **`cors_origins: list[str]` 配 JSON 数组**：pydantic-settings 自动 json 解析；默认兜底 `["http://localhost:5173"]`
- **health 不内联**：仍走 routers 挂载 `prefix="/api"`——示范了「所有 HTTP 入口进 routers」的分层
- **日志**：stdlib logging + 级别读自 settings（`LOG_LEVEL=DEBUG` 实测生效），无 print

## 一处「未来注意」非阻塞点（讲给学生听，不返工）
`setup_logging` 用 `basicConfig(force=True)` 会重置 root logger；uvicorn 有自己那套 `uvicorn.*` 日志级别（`--log-level`），和我们的 `LOG_LEVEL` 是**两套概念并存**。现在可用；M6/D39 做可观测性时统一 `logging.config.dictConfig` 收口。别现在改。
