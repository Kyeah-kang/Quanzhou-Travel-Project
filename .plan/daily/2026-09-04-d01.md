## 3 个新概念
1. **Monorepo（单仓多模块）**：后端/前端/数据/文档放同一 git 仓库，改一次提交全同步，适合个人项目；代价是构建物要彼此隔离。
2. **前后端分离**：React 只做 UI，通过 REST/SSE 调 FastAPI；后端不关心页面，只暴露 API → 可独立部署、可换前端、可被别的端复用。
3. **模块化 + 一天一块**：把大系统切成"可独立运行、可单独验收"的小模块，每天掌握一块，降低认知负荷、进度可控。
